# ⏱️ Digital Clock

A modern, stylish, and minimalist real-time digital clock built using vanilla web technologies. It features smooth block-styled numbers with a vibrant purple gradient background.

## 🚀 Features
* Real-time tracking of hours, minutes, and seconds[cite: 10].
* Automatic leading-zero formatting (e.g., `09` instead of `9`) for a clean look[cite: 10].
* Modern UI design with CSS Flexbox and smooth box shadows[cite: 8].

## 🛠 Technologies Used
* **HTML5** (Semantic structure)[cite: 9]
* **CSS3** (Linear gradients, Flexbox alignment, Google Fonts styling)[cite: 8]
* **JavaScript (ES6+)** (`setInterval`, Date object manipulation, DOM text updates)[cite: 9, 10]

## 💻 How to Run
1. Clone or download this repository.
2. Open `index.html` in any web browser[cite: 9].

# ⏱️ Цифровые часы

Современные, стильные и минималистичные цифровые часы реального времени, созданные с использованием чистых веб-технологий. Проект выполнен в виде блоков с цифрами на красивом фиолетовом градиентном фоне.

## 🚀 Особенности
* Отслеживание часов, минут и секунд в реальном времени[cite: 10].
* Автоматическое добавление ведущего нуля (например, `09` вместо `9`) для аккуратного внешнего вида[cite: 10].
* Современный дизайн интерфейса с использованием CSS Flexbox и объемных теней[cite: 8].

## 🛠 Используемые технологии
* **HTML5** (структура разметки)[cite: 9]
* **CSS3** (линейные градиенты, выравнивание Flexbox, стилизация шрифтов)[cite: 8]
* **JavaScript (ES6+)** (функция `setInterval`, работа с объектом Date, обновление DOM)[cite: 9, 10]

## 💻 Как запустить
1. Клонируйте или скачайте этот репозиторий.
2. Откройте файл `index.html` в любом веб-браузере[cite: 9].
